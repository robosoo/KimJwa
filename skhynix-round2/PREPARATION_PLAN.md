# 비개발 직군의 준비물과 전체 리허설 계획

기준일: 2026-10-25. 현재 작업 브랜치의 파일을 점검한 결과다. 개인 기기의 자료·수행 이력은 미조사다.

## 확인한 상태

| 항목 | 현재 상태 | 판단 근거 |
|---|---|---|
| 범용 실행 키트 | 문서 틀 있음 · 실행 키트 미확인 | 추가 제공된 인터뷰 MVP의 13개 문서를 확인. 샘플 검사 통과와 제품 완성은 별개 |
| 검증된 오픈소스 목록 | 미준비 | 목적·고정 버전·라이선스·설치·실행 결과가 연결된 후보 목록 없음 |
| 전체 시간 리허설 2회 | 실행 기록 없음 | 가상 자료·해설·타이머는 있음. 실제 AI 작업과 산출물·검증·설명 기록은 없음 |

참가자의 “어느 도메인도 80% 해결하는 키트”는 회고의 희망 사항이며 검증된 성능이나 합격 조건이 아니다. 비개발자에게 웹 앱·FDE 키트 구축을 의무로 두지 않는다.

## 우선 준비할 것

1. 주최측 개별 안내에서 직군별 과제·시간·제출 형식·허용 AI·인터넷·파일 반입·업무 서비스 사용 범위를 확인한다. 미확인 항목을 추측으로 메우지 않는다.
2. 허용 도구에서 문서·표를 열고 결과 파일을 저장한 뒤 다시 열어 확인한다. 실제 사용 가능한 환경이 확정되기 전에는 특정 도구 설치가 필요하다고 단정하지 않는다.
3. 짧은 서식 네 가지를 준비한다: 목적/성공 기준/제약/제외 범위, 결정과 기각 이유, 원자료-결론 검증표, 현재 상태/미검증/다음 행동 인수인계. 서식 존재와 실제 검증 완료는 다르다.
4. 외부 코드는 과제가 요구할 때만 검토한다. 아래 후보 검토표의 근거가 채워지기 전에는 ‘검증된 추천’으로 표시하지 않는다.

후보 검토 항목: 해결할 업무, 원본 저장소, 고정 버전/커밋, 라이선스, 지원 형식, 설치·적응 시간, 실행 명령, 입력과 기대값, 실제 결과, 보안·인터넷·반입 제약, 채택/기각 이유. 현재 추천 저장소를 임의로 지정하지 않았다.

## 전체 리허설 1 — 검사 자료의 조사 후보 보고

학습센터의 가상 Lot 자료를 사용한다. 실제 출제 문제나 공정 기준이 아니다.

- 결과물: Lot별 계산표, 중복·결측 처리 목록, 조사 후보와 근거, 확정할 수 없는 내용과 다음 확인 사항을 담은 한 장 메모.
- 검증: 원본 6행/고유 Lot 5개, 계산 가능한 행의 합계 157/3500, R2의 합계 115/1500을 대조한다. 빈 분모를 채우지 않는다. 5%와 5% 초과, 중복 기준, 인과 판단 한계를 설명한다.
- 수행: 안내 읽기→필요한 조건 확인→범위 합의→AI로 초안→별도 계산/대조→최종 파일 열기→AI 없이 자기 설명. 실제 결과와 예상값을 따로 기록한다.
- 종료 증거: 실제 산출물, 사용한 자료·AI 지시, 대조 계산, 실패·미확인 목록, 약점→영향→다음 검증의 설명 기록.

## 전체 리허설 2 — 일정과 품질 승인 판단

첫 리허설의 실패를 수정한 뒤 학습센터의 가상 일정·품질 승인 자료를 사용한다.

- 결과물: 일정 대안표, 자원 충돌/승인 필요 항목, 조건부 권고안, 담당자에게 확인할 사항.
- 검증: 총시간이 같아도 일정의 실행 가능성과 품질 승인은 별개다. 승인 근거 없는 단축·우회안을 확정하지 않는다.
- 비교: 첫 리허설 준비물을 얼마나 재사용했는지, 설치·적응 시간보다 절약 시간이 큰지, 놓친 조건이 줄었는지 확인한다.
- 종료 증거: 대안 채택/기각 이유, 실패 조건 대조, 최종 문서 열림, 자기 결과물에 대한 구두 설명.

실제 제한 시간이 확인되면 그 시간으로 수행한다. 확인 전 사이트의 4시간 타이머는 자율 훈련용일 뿐이다. 시간 배분을 고정 배점표로 사용하지 않는다. 두 리허설 모두 실행 전이므로 이 계획서만으로 완료 처리하지 않는다.
