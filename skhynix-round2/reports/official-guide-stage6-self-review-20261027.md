# 2026-10-27 · SK하이닉스 2차 공식 가이드 6단계 자체 QA

검토 성격: 모델 자체 검토. 제3자 심사위원·실제 사용자 패널·주최측 검증은 실시하지 않았음.
원자료: 참가자 제공 「1_시험_필수확인사항_브리프.pdf」 p.1, 「3_사전_체험_및_응시환경_상세_가이드.pdf」 pp.3~5.
중요: 문서에 없는 실제 출제 문항·문항별 배점·심사 기준·제출 파일명은 확정하지 않음.

## 구현 범위
- 미리보기 → 되돌리기 → 최종 확정 재확인 → 질문 생성 대기·재시도 → 서술형 시작 → 6문항 → 완료 확인 7화면.
- 미리보기 목록은 전체 제출 파일 목록이 아님, 확정 후 파일 수정 불가.
- 일반 대기 약 5분과 안내 화면 예상 최대 10분, 자동 재시도 시 재시작 가능성 구분. 질문 대기 타이머 ≠ 문항 답변 타이머.
- 본격 답변 타이머는 1번 '문제 풀기' 클릭 후, 2번부터 이전 답안 제출 즉시 시작한다는 사실 강조.
- 실제 PDF의 모의 화면 '5문항'과 브리프의 실제 6문항 차이 명시.
- AI 사용 및 붙여넣기 금지, 6문항 직접 답변, 자동 시간 만료 확정, 이전 문항 수정·이동 제한.
- 14시 전체 종료와 시간 예시 2개. 실제 종료 화면의 제출 ID/시각/파일수/크기 확인.
- 12문항 설명식 퀴즈, 15개 사전 제출 체크박스.

## 자체 피드백 및 실제 수정
1. '제출하고 문제풀기'를 최종 확정으로 혼동하는 위험 → 미리보기 버튼과 별도 확정 재확인 화면 분리.
2. '예상 최대 10분'을 5분 서술형 답변시간으로 혼동 → 별도 질문 준비 단계, 모의 재시도 표시 추가.
3. 실제 6문항 vs 화면 예시 5문항 혼란 → 공식 브리프 명시와 예시 이미지 차이 설명.
4. 답변 서술형을 이 학습 웹사이트에 남길 수 있는 위험 → 답변은 브라우저 메모리에서만 다루고, 문항 이동 시 값 삭제. localStorage에는 체크 상태만 기록.
5. 실제 시험 서술형 AI·복사·붙여넣기 금지 → 학습 textarea에 paste/drop 방지 및 금지 설명 표시.
6. 가상 타이머가 실제 5분 카운트다운으로 보일 위험 → 모의실습에는 05:00 표시 예시만, 수동 '시간 만료 시연' 버튼임을 반복 명시.
7. 14:00 마감이 문항 6개×5분보다 우선하는 점을 놓칠 위험 → 13:00 확정/13:05 시작 및 13:55 시작 예시를 추가함.
8. 처음 만든 자체 런타임 테스트의 기대 순서가 1칸 어긋남 → 테스트의 예상 순서를 고쳐 재실행해 PASS. 콘텐츠 기능 문제가 아닌 검증 스크립트 오류였음.

## 정적 검수
- 7개 앵커 모두 유지, 1~5단계의 기존 콘텐츠 유지.
- 6단계: 서술형 학습 단계 7개, 문항 12개 모두 해설·공식 페이지 근거, 체크 항목 15개.
- Stage6 script 및 기존 inline JS 구문 검사 통과.
- 홈에서 1~6단계 모두 직접 링크.
- 개인정보·시험 파일 저장·외부 업로드 기능이 새 모의실습에 없음.

## 동작 검수 · 간이 DOM 모의 환경
- 브라우저가 아닌 메서드 기반 가짜 DOM 테스트에서 아래 사용자 이벤트를 실행해 PASS:
  미리보기 열기/닫기, 최종 확정 전 취소, 제출 확정 후 준비 단계 전환, 질문 재시도,
  첫 문항 시작, 빈 답변 수동 제출 차단, 답변 제출→다음 문항 이동,
  textarea 복사·붙여넣기 및 드롭 차단, 가상 시간 만료를 통한 마지막 문항 완료,
  첫 화면 재시작, 퀴즈 답변 집계, 체크리스트 상태 저장.
- 실제 HTML 레이아웃·iPad Safari와 키보드 포커스/스크린리더는 모의 DOM 검사가 검증하지 못함.
