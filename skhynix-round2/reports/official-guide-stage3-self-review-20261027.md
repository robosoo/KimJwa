## 교재 구현 범위
- 6개 클릭형 IDE 모의 영역: Explorer, Editor, Terminal, Browser, Messenger, 상단 바. 실제 시스템 연결 없는 시뮬레이션이라고 명시.
- 문의 대상 구분: Cofa Helper(플랫폼 사용법), 업무 담당자(업무 맥락), 문제 신고(반복 오류).
- 명령: codex -> /status -> /model -> 첫 프롬프트 -> 승인/거절 -> 확인. /modeL OCR/표기 혼동 위험 설명. 개인 API 키 요구 없음.
- 상태: 승인 대기, 실행 중, 완료. 결과 직접 검증 및 과제 제출과 요청 완료의 차이.
- Ctrl+Shift+V/ Ctrl+C / 새 터미널 / 서버 유지 / 실제 포트와 0.0.0.0 바인딩.
- 사례 판단 10문항, 준비 체크박스 10개(브라우저 로컬 저장).

## 자체 피드백 → 수정
1. 초보자가 AI의 명령을 모두 승인하는 습관을 배울 수 있음: 승인만 있는 터미널 연습에서 '거절' 버튼과 별도 모의 결과 안내를 추가.
2. Cofa Helper와 업무 담당자를 혼동할 수 있음: 실제 질문 유형 3개를 선택하면 문의할 대상이 표시되도록 구성.
3. AI 실행 완료 = 과제 완료라고 오해할 수 있음: 상태 3개를 독립 설명하고 완료 후 파일·테스트·브라우저 확인을 강조.
4. /model 문자 표기 모호함: 공식 PDF의 추출 텍스트에 /modeL로 보이는 부분이 있어 실제 시험 터미널의 모델 선택 명령 안내가 우선함을 명시.
5. 초보자에게 실제 CLI를 흉내낸 UI가 혼동될 수 있음: 테스트용 가상 IDE·가상 터미널이며 서버 호출/코드 변경이 전혀 없다는 안내를 위·아래 반복 배치.
6. 좁은 화면에서 IDE/상태 3열 및 표가 밀릴 위험: 단계 3 전용 작은 화면 CSS에서 IDE 도구를 줄바꿈, 상태 카드를 1열, 표를 수평 스크롤 처리.
