# SK하이닉스 AI 해커톤 2차 학습센터 · 교육심리학 근거 기반 설계 감사
**검토일:** 2026-10-28 / **범위:** GitHub 브랜치 `skhynix-round2-unified-20261025` 및 Vercel 운영 배포 `dpl_Gu4mZD5XcejxdTutwSoXpYGrS27s`.

> 이 문서는 학습 사이트 소스·JSON 학습 자료에 대한 설계 평가다. 실제 학습자 실험, iPad Safari 화면 검증, 학습 성과 측정은 수행하지 않았다. 이 사이트가 논문에서 관찰된 효과 크기를 그대로 달성한다고 주장할 근거는 없다.

## 실제 구성 확인
- `index.html`: 시작하기에 6단계 시험 지도와 단계별 안내, 주최 측 단서 역추적, Skill/Plugin 추천이 같은 스크롤에 있다. 메인 콘텐츠 안에 설명용 표 10개, 링크 47개, 전체 주요 섹션 27개.
- `app.js`: 네 메뉴 (시작하기 / 후기·근거 / 전략·실습 / 이해도 확인), 기존 39개 읽기 항목 탐색, 8단계 가상 풀이, 가상 사례·가상 실무자 문답, 즉시 피드백형 12문항, 읽음·오답 로컬 상태 저장.
- `learning-path.json`: 단일 Lot 가상 데이터셋의 완성 예시 1개 → 8개 단계별 정답 선택 → 최종 보고 예시. 8단계는 숫자만 바꾼 같은 유형에 가까운 전이 문제를 포함.
- `portal-content.json`: 8개 서로 다른 상황 기반의 자료 분석 연습; 해결 기준 및 원자료 포함.
- `beginner-guide.json`: 22개 용어 설명, 3단계 권장 학습 순서.
- `source-manifest.json`: 공식 사실·이전 행사 경험·가상 사례의 출처 구분 정책.
- `app.js`: 실전용이 아닌 '4시간 자율 훈련 타이머'와 '3분 구두 연습'이 존재. 실제 과제 풀이 180분 및 후속 6문항×5분과 혼동되지 않게 명확한 분리 권장.
- 현재 JavaScript는 오답·읽음 상태를 저장하지만, 날짜가 지난 뒤 다시 풀도록 지정하는 간격 복습 로직은 확인되지 않는다.

## 우선순위별 개선 제안 — 기존 심플한 UI 유지
### P0 · 학습→실습 동선 연결
- 시험 6단계 지도는 그대로 최상단 유지.
- 그 아래 설명 문구에 가벼운 텍스트 링크로 `실습 8단계 시작`, `12문항 확인`, `주최 측 분석`, `Skill/Plugin`만 배치. 새 버튼/메뉴/아코디언 추가하지 않음.
- 처음 공부하는 사람에게는 '필수: 시험 흐름→완성 예시→8단계 풀이→12문항→다른 사례 1개'를 명확히 알려줌. 장문 리서치는 참고로 격리.

### P1 · 자기 설명 + worked example fading
- 새 UI보다 기존 8단계 풀이에 2곳만 학습자 자기 설명 질문을 추가: '분모를 제외한 이유는?' '왜 인과관계를 확정할 수 없나?'
- 후반 1~2단계는 해설을 보기 전에 생각해 본 뒤 대조하도록 진행. UI 구현은 최소화.
- 실제 시험 6×5분 서술형에 대비해 선택형 정답과 별개로 자신의 결과물·파일·실패 조건을 말로 설명하는 연습 연결.

### P1 · 짧은 간격 복습
- 현재 오답 기록을 이용해 다음 날 또는 시험 전날 3~5개 문항을 다시 보게 하는 간단한 안내(앱 내 자동 일정 엔진 필수 아님).
- 10/28 학습 → 10/29 해설 가리고 인출 → 10/30 다른 사례 재해결 → 10/31 시험이라는 실제 시간에 맞게 구성.
- 정답 문항도 일부 다시 풀어야 함. 즉시 재답만으로 학습 확인하지 않기.

### P1 · 새로운 업무 문제로 전이
- 같은 Lot 데이터만 반복해 수치 정답을 기억하는 위험을 줄이기 위해 8개 중 재고 배분·이벤트 중복·Prompt Injection에서 하나를 독립 수행 대상으로 추천.
- 각 사례의 최소 완료 기준은 입력·정상값·예외·출처·재검증·미확인 항목의 6개 조건을 따르되, 복잡한 평가 UI 추가는 피함.

### P2 · 시간/규정 문구
- '4시간 자율 훈련', '3분 구두 연습'에 '공식 시험 시간 아님' 구분을 더 눈에 띄게 하고 실제 180분 구현 + 6문항×5분 안내로 연결.
- 오래된 JSON의 '2차 환경 미확정' 설명은 10/26 공식 안내에서 확인된 플랫폼·시간·장비 부분에 한해 갱신. 실제 과제·세부 배점 미공개는 유지.
