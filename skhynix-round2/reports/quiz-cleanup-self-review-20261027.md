# 학습센터 중복 고정 문제 제거 · 자체 QA (2026-10-27)

사용자 요청: GPT 튜터와 중복되는 쓸데없는 질문·문제 영역 삭제. 기존 학습·유용한 인터랙티브 조작 기능은 보존.

## 제거한 영역
- 1단계: 4개 O/X 퀴즈와 중복 준비 체크리스트.
- 2단계: 8개 O/X 퀴즈와 중복 준비 체크리스트.
- 3단계: 10개 O/X 퀴즈와 중복 준비 체크리스트.
- 4단계: 12개 정적 허용/금지 판별 문제, 중복 체크리스트.
- 5단계: 12개 O/X 퀴즈, 중복 체크리스트.
- 6단계: 12개 O/X 퀴즈, 중복 체크리스트.
- 7단계: 12개 고정 장애상황 퀴즈와 8개 감독 경고 판별 퀴즈.
- GPT 학습 튜터: 미리 준비한 예시 질문 버튼 5개. 텍스트 자유 질문 UI는 유지.
- 퀴즈를 렌더링·채점·저장하던 관련 JavaScript 핸들러 삭제.

## 보존한 실질 학습
- 7단계 공식 출처·시간·감독·GitHub/Skill/MCP·제출 규정.
- 2단계 신분증 종류 선택과 가림범위 확인.
- 3단계 가상 IDE·Codex 승인/거절 모의 터미널.
- 4단계 GitHub/Skill/MCP 개념 전환, 실전 적용 지시문 생성.
- 5단계 Browser 연결/포트/바인딩, 파일 저장 충돌 시뮬레이터.
- 6단계 제출 미리보기→최종 확정→문항 타이머 진행 시뮬레이터(타이밍·조작 연습, 실제 시험 문항 아님).
- 7단계 문제 신고 작성 보조, 시간 계산, 종합 리허설과 **단일 최종 체크리스트**.
- 기존 학습센터 메뉴와 별도 실전형 실습/자료. 반복 O/X 제거가 모든 문제형 학습의 폐지를 뜻하지 않음.
- 단계별 AI 튜터 연결. 실제 시험 중 외부 GPT 사용 금지 및 API 키 미설정 상태 안내 유지.

## 코드 QA
- 제거된 문제 영역 1~7단계 HTML ID 정적 검사 PASS.
- 중요한 실습 요소 및 마지막 7단계 체크리스트 남아 있음 PASS.
- 7개 stage 앵커와 GPT 튜터 링크 보존 PASS.
- 본문 inline JavaScript 3개 + 단계별 외부 JavaScript 4개 + GPT 튜터 스크립트 구문 검사 PASS.
- 제거한 퀴즈 ID를 참조하는 단계별 외부 JS 잔존 없음 PASS.
