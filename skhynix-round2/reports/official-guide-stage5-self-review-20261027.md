# SK하이닉스 2차 공식 시험 가이드 · 5단계 자체 QA

기록일: 2026-10-27
검토: AI 자체 검토(비개발자 UX / 공식 규정 준수 / 정적 기능 QA). 실제 심사위원·독립 전문가 패널의 평가 아님.

## 출처
- 사용자 제공 공식 PDF 「3_사전_체험_및_응시환경_상세_가이드」 2~3쪽의 웹 IDE·Browser·파일 작성/저장·충돌 안내.
- 같은 문서 5쪽의 연결 문제 대응과 외부 도구 제한.
- 공식 미공개: 실제 과제 주제, 제출 파일명, 특정 기술 스택, 서버 고정 포트, 채점 배점 및 평가식.

## 구현 내역
- 5개 단계별 확인 질문, 공식 Browser의 PORT→URL→새로고침→기능 확인 흐름.
- 가상 Browser 연결 실습: 서버 시작·중지, PORT 3000과 가상 실제 포트 4173 비교, localhost vs 0.0.0.0, 경로 오류, 연결 후 입력·추가 기능.
- Browser 문제 해결: 서버 종료/로그, 실제 PORT, 바인딩, URL 순서.
- 자동 저장·저장 실패·U/M·외부 변경·디스크 삭제 상태 표.
- AI/터미널이 같은 파일을 변경한 경우: 에디터와 디스크 내용을 나란히 비교, 외부 변경 불러오기와 현재 내용으로 저장의 차이.
- 직접 검증 증거 매핑, 학습 프롬프트, 12개 상황 판단 문항과 출처, 체크리스트 12개 로컬 저장.
- 기존 학습센터의 4개 메뉴, 기존 PDF 학습 1~4단계, 기존 프로그램 파일 보존.

## 자체 피드백과 반영
1. 초보자가 AI '완료'와 프로그램의 실제 기능 검증을 혼동할 가능성 → Browser에서 버튼·입력·이동 테스트를 별도 단계로 분리.
2. 가이드 예시 PORT 3000을 시험 고정값으로 오해할 가능성 → 임의 예시 4173을 사용하고 터미널 표시 값 확인을 반복 안내.
3. localhost 전용 바인딩의 미리보기 연결 실패 가능성을 확정된 실패로 오해할 가능성 → '연결되지 않을 수 있음'으로 공식 표현 유지.
4. 저장 충돌 두 선택지 중 하나가 언제나 정답이라고 오해할 위험 → 양쪽 버전 비교, 선택에 따른 덮어쓰기/교체 차이를 표시.
5. PDF에는 '디스크에서 삭제됨' 복원 방법이 상세히 기재되지 않음 → 초기 실습의 자동 복원 시뮬레이션을 삭제하고 확인 필요 안내로 수정.
6. 퀴즈 이벤트 코드에 불필요한 전체 문항 검색이 끼어 있음 → 개별 문항 이벤트 직접 등록으로 변경.
7. 모바일에서 입력 폼·에디터 비교 2열이 좁아질 위험 → 640px 미만에서 한 열로 변경.

## 검증 한계
- 실제 브라우저에서 클릭·입력·저장 복원·iPad Safari 동작을 실측한 것은 아님. Vercel READY는 런타임 QA 합격을 뜻하지 않아.
- 웹 뷰어에서 운영 HTML 요청을 시도했으나 접근 불가. 가상 실습은 실제 플랫폼과 완전히 동일한 UI 또는 네트워크 구현을 보장하지 않아.
- 공식 안내에 없는 경우(예: 삭제된 디스크 파일의 실제 복원 버튼 동작)는 구현에서 확정적으로 묘사하지 않음.
