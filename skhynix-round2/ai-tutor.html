GPT API 연결을 위한 마지막 설정

현재 Vercel 프로젝트에 서버 비밀키가 아직 설정되지 않았어. 사이트 코드는 준비돼 있고, Vercel 환경 변수 두 개를 프로젝트 관리자만 추가해야 실제 GPT 응답이 활성화돼.

OPENAI_API_KEY · OpenAI API 계정의 비밀키. 절대로 HTML·GitHub·학습 채팅창에 붙여넣지 말고 Vercel의 환경 변수에 설정해.

TUTOR_ACCESS_CODE · 외부에서 유료 API를 마음대로 호출하지 못하도록 보호하는 학습실 접속 코드. 충분히 긴 임의의 값을 직접 설정한 뒤 위 입력칸에 입력해.

OPENAI_MODEL · (선택) 기본값 gpt-5-mini. 계정에서 지원하는 모델로 변경 가능.

Vercel 프로젝트 skhynix-ai-hackathon-round2-lab → Settings → Environment Variables → Production을 선택하고 저장한 뒤 재배포하면 돼. API 사용량·결제 한도는 OpenAI 플랫폼에서 별도 관리해야 해.

설정 전에는 GPT 답변이 나오지 않아. 학습 가이드와 기존 문제 풀이는 정상적으로 사용할 수 있어.
