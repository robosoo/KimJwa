STEP 01 · 상세 학습 적용

시험의 4시간은 어떻게 흘러갈까?

시험은 10월 31일 토요일 10:00부터 14:00까지야. 09:40까지 접속해 준비하라는 안내가 있지만, 09:40이 입장 마감이라는 뜻은 아니야. 시작 후에도 재입장이 가능해. 다만 전체 종료 시각은 14:00으로 고정돼 있어. [공식 · 브리프 1쪽 / 상세 1·5쪽]

180분과제 풀이 최대 시간
약 5분후속 질문 준비 일반 안내
6 × 5분후속 서술형 6문항·총 30분

실제 진행 순서

09:40까지 접속 권고
개인 응시 링크 → 규정 동의 → 감독 연결

웹캠과 전체 화면 공유, 휴대폰 Proctor 연결을 준비해. 연결만으로 녹화가 시작되지는 않아.

10:00 이후 · 과제 시작을 누르는 순간
과제 타이머 시작 + 녹화 자동 시작

그 직후 안내된 휴대폰 거치·신분증·안경 확인 절차를 진행해. 과제 풀이 시간은 최대 180분.

과제 작업 중
README → 업무 담당자 질문 → Codex 작업 → 직접 검증

제출 미리보기를 보는 동안에도 과제 타이머는 흐르고 있어.

과제 제출 확정
파일이 고정되고, 서술형 질문 준비 시작

일반 안내는 약 5분. 상세 가이드에는 화면상 예상 최대 10분 및 자동 재시도 가능성도 설명돼 있어.

문제 풀기를 누르는 순간
첫 서술형 문제의 5분 타이머 시작

이후 문항은 이전 답안을 제출하는 순간 다음 타이머가 바로 시작돼. 확정한 답변은 수정할 수 없어.

모든 문항 제출 후
완료 화면에서 제출 ID · 시각 · 파일 수 · 크기 확인

정상 완료 화면이 나타나면 14:00까지 기다리지 않고 퇴장할 수 있어.

숫자 때문에 헷갈리는 부분

궁금한 상황정확한 해석
180분 + 30분이면 13:30에 끝나나?아니야. 대기 시간이 별도로 발생하며, 시작·제출 시점에 따라 달라져. 14:00 전체 종료만 고정이야.
10시에 시작해서 180분을 다 쓰고 질문 준비가 5분이라면?[계산 예시] 13:00에 과제 종료, 13:05 서술형 시작, 13:35에 서술형 30분 종료. 25분은 보장된 휴식 시간이 아니야.
질문 준비 시간이 5분을 넘으면?상세 가이드에는 예상 최대 10분 표시 및 재시도 시 시간 재시작 가능성이 있어. 5분 완료가 보장되는 것은 아니야.
13:30에 문제를 풀다가 14:00이 되면?개별 타이머가 남았더라도 14:00에 모두 종료. 그때까지 입력한 내용만 반영돼.
시험 시작 버튼을 늦게 누르면?본 과제는 최대 180분이지만 14:00 이전에 서술형까지 마쳐야 하므로 실제 남은 전체 시간이 줄어들 수 있어.

놓치면 안 되는 5가지 세부 규정

① 사전 체험 15분도 과제 풀이 180분에 포함되나?
포함되지 않아. 응시 링크를 받은 뒤 본 과제 시작 전까지 1회, 15분 동안 따로 사용해. 연습 과제와 예시 답변은 평가에 반영되지 않아. [공식 · 상세 2쪽]
② 과제를 빨리 끝냈으면 180분을 다 기다려야 하나?
기다릴 필요 없어. 최소 응시 시간은 없어. 작업을 마친 후 제출을 확정하고 후속 서술형까지 완료하면 종료 가능해. [공식 · 브리프 1쪽 / 상세 3·5쪽]
③ 과제 작업 10분 전 제출은 의무인가?
권장사항이야. 가이드는 작업 시간 종료 10분 전부터 제출을 시작할 것을 권장해. 그 전에 파일 경로와 저장 상태를 확인해야 해. [공식 · 상세 3쪽]
④ 새로고침·재접속·오류 신고를 하면 타이머가 멈추나?
멈추지 않아. 같은 개인 링크로 재접속 가능하지만 시간은 초기화되지 않고, 저장되지 않은 수정 사항은 보존이 보장되지 않아. [공식 · 상세 5쪽]
⑤ 화장실에 가거나 식사해도 되나?
화장실 등 자리 이탈의 상세 규칙은 당일 09:50 별도 이메일로 안내 예정이야. 식음료는 감독 영상과 모니터 화면을 가리지 않는 조건으로 허용되지만 타이머는 계속 흐른다고 명시돼 있어. [공식 · 브리프 1쪽 / 상세 3쪽]

잘못 이해하기 쉬운 문장

가이드의 화면 예시 5문항 ≠ 실제 문항 수. 안내에서 공식 명시한 후속 서술형은 6문항이야. 일부 화면 이미지의 '5개'는 조작 안내를 위한 예시 수치야. [공식 · 브리프 1쪽 / 상세 4쪽]

이해했는지 직접 확인하기

아래는 공식 문제나 실제 채점 문항이 아닌 학습용 확인 문제야.

1. 09:40 이후에는 시험장에 들어갈 수 없다.

2. 후속 서술형은 6문항이고 AI를 사용할 수 없다.

3. 질문 준비는 반드시 5분 안에 끝난다.

4. 시험 화면에 다시 접속해도 타이머는 초기화되지 않는다.
