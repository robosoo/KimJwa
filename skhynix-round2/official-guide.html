시험의 4시간은 어떻게 흘러갈까?

시험은 10월 31일 토요일 10:00부터 14:00까지야. 09:40까지 접속해 준비하라는 안내가 있지만, 09:40이 입장 마감이라는 뜻은 아니야. 시작 후에도 재입장이 가능해. 다만 전체 종료 시각은 14:00으로 고정돼 있어. [공식 · 브리프 1쪽 / 상세 1·5쪽]

제출 미리보기를 보는 동안에도 과제 타이머는 흐르고 있어.

과제 제출 확정
파일이 고정되고, 서술형 질문 준비 시작

일반 안내는 약 5분. 상세 가이드에는 화면상 예상 최대 10분 및 자동 재시도 가능성도 설명돼 있어.

문제 풀기를 누르는 순간
첫 서술형 문제의 5분 타이머 시작

이후 문항은 이전 답안을 제출하는 순간 다음 타이머가 바로 시작돼. 확정한 답변은 수정할 수 없어.

모든 문항 제출 후
완료 화면에서 제출 ID · 시각 · 파일 수 · 크기 확인

정상 완료 화면이 나타나면 14:00까지 기다리지 않고 퇴장할 수 있어.

숫자 때문에 헷갈리는 부분

궁금한 상황정확한 해석
180분 + 30분이면 13:30에 끝나나?아니야. 대기 시간이 별도로 발생하며, 시작·제출 시점에 따라 달라져. 14:00 전체 종료만 고정이야.

13:30에 문제를 풀다가 14:00이 되면?개별 타이머가 남았더라도 14:00에 모두 종료. 그때까지 입력한 내용만 반영돼.

놓치면 안 되는 5가지 세부 규정

① 사전 체험 15분도 과제 풀이 180분에 포함되나?
포함되지 않아. 응시 링크를 받은 뒤 본 과제 시작 전까지 1회, 15분 동안 따로 사용해. 연습 과제와 예시 답변은 평가에 반영되지 않아. [공식 · 상세 2쪽]
② 과제를 빨리 끝냈으면 180분을 다 기다려야 하나?
기다릴 필요 없어. 최소 응시 시간은 없어. 작업을 마친 후 제출을 확정하고 후속 서술형까지 완료하면 종료 가능해. [공식 · 브리프 1쪽 / 상세 3·5쪽]
③ 과제 작업 10분 전 제출은 의무인가?
권장사항이야. 가이드는 작업 시간 종료 10분 전부터 제출을 시작할 것을 권장해. 그 전에 파일 경로와 저장 상태를 확인해야 해. [공식 · 상세 3쪽]
④ 새로고침·재접속·오류 신고를 하면 타이머가 멈추나?
멈추지 않아. 같은 개인 링크로 재접속 가능하지만 시간은 초기화되지 않고, 저장되지 않은 수정 사항은 보존이 보장되지 않아. [공식 · 상세 5쪽]
⑤ 화장실에 가거나 식사해도 되나?
화장실 등 자리 이탈의 상세 규칙은 당일 09:50 별도 이메일로 안내 예정이야. 식음료는 감독 영상과 모니터 화면을 가리지 않는 조건으로 허용되지만 타이머는 계속 흐른다고 명시돼 있어. [공식 · 브리프 1쪽 / 상세 3쪽]

잘못 이해하기 쉬운 문장

가이드의 화면 예시 5문항 ≠ 실제 문항 수. 안내에서 공식 명시한 후속 서술형은 6문항이야. 일부 화면 이미지의 '5개'는 조작 안내를 위한 예시 수치야. [공식 · 브리프 1쪽 / 상세 4쪽]

2. 개인 링크 접속부터 감독 연결까지

아래 순서는 공식 상세 가이드 1페이지에서 제시한 감독 환경 설정 순서야.

입장 ①
개인 접속 링크 열기 → '계속'

접속 코드는 미리 입력되어 있어. 별도 입력을 요구하는 단계로 단정하면 안 돼.

입장 ②
'응시 규정 확인'을 끝까지 스크롤 → 동의 → 다음

스크롤을 완료해야 동의할 수 있는 화면이 안내돼 있어. 시험 규정을 실제로 확인한 후 동의해.

감독 ①
감독 안내 동의

감독 기록·카메라·전체 화면의 소리 없는 녹화와 저장에 관한 안내를 확인해.

감독 ②
컴퓨터 웹캠 확인

브라우저 카메라 권한을 허용하고 얼굴 전체와 양쪽 귀, 밝기·화각을 확인해.

감독 ③
'전체 화면' 공유 선택

브라우저의 선택창에서 '창'이나 '탭' 대신 전체 화면을 선택해야 연결이 완료돼.

감독 ④
휴대폰 Cofa Proctor 설치·연결

설치용 QR과 연결용 QR을 구분해 순서대로 연결하고 PC 화면에 연결 완료 표시가 나오는지 확인해.

영상 기록 세부사항

공식 가이드에는 컴퓨터 전체 화면과 카메라 영상이 소리 없이 녹화·저장되고, 녹화 영상이 60초 단위로 서버에 전송된다고 안내돼 있어. 실제 녹화 시작 시점은 '과제 시작' 버튼을 누른 순간이며, 사전 체험의 카메라 영상은 녹화 저장하지 않는다고 명시돼 있어. [공식 · B 1~2쪽]

3. 휴대폰 QR 두 개의 차이

① 설치용 QR휴대폰의 기본 카메라로 스캔 → Cofa Proctor 설치
② 연결용 QRCofa Proctor 앱 안에서 스캔 → 해당 응시 세션 연결

실제 조작 순서: PC의 모바일 카메라 영역에서 '연결하기' → 휴대폰 기본 카메라로 설치 QR 스캔·설치 → PC에서 '설치했어요 · 연결하기' → 휴대폰 Proctor 앱으로 응시 연결 QR 스캔 → PC에 연결 완료가 표시되는지 확인.

여기에는 실제 QR 이미지를 넣지 않았어. 공식 PDF의 QR은 화면 설명용 예시이고 실제 설치·연결은 시험 화면에서 제시되는 QR로 해야 해. [공식 · B 1쪽]

4. '과제 시작' 이후에 해야 하는 본인 확인

과제 시작 클릭 직후
자동 녹화 시작

별도 녹화 버튼을 누르는 게 아니야. 아래 본인 확인은 녹화가 시작된 후 진행해.

휴대폰 세로 거치
옆으로 펼친 팔의 손끝이 닿는 책상 위에 거치

응시 의자에 앉은 자세에서 한쪽 팔을 옆으로 펼쳐 위치를 잡아. 휴대폰 전면 카메라에 손·키보드·얼굴·모니터가 함께 보이도록 높이와 각도를 조절하고 충전선을 연결해.

실물 신분증 확인
미리 개인정보를 가린 신분증을 얼굴 옆에 들어 Proctor 카메라에 제시

주민등록증·운전면허증·여권 중 하나. 모바일 신분증은 사용할 수 없어. 다음 표에서 종류별 가림 범위를 확인해.

안경 착용자에 해당하는 경우
안경 앞면, 양쪽 다리의 바깥쪽·안쪽을 보여준 뒤 재착용

스마트 안경 여부 확인과 연관된 절차로 안내돼 있어. 공식 순서대로 확인해.

5. 신분증 종류별 가림 범위 — 직접 선택해 확인

신분증 사진이나 번호는 이 사이트에 입력·업로드하지 않아. 아래 안내만 보고 종이나 손가락으로 가릴 곳을 준비하면 돼.

주민등록증

가리기: 주민등록번호 뒤 7자리와 주소

보이기: 사진, 이름, 주민등록번호 앞 6자리(생년월일)

개인정보면의 여러 곳을 가려야 하면 전부 가려야 해. 사진·이름 등 본인 확인 항목은 가리지 않도록 주의해. [공식 · B 2쪽]

6. 딱 한 번 제공되는 15분 사전 체험

1회·15분. 개인 응시 링크를 받은 뒤부터 본 과제를 시작하기 전까지 대기 화면의 '사전 체험하기'를 눌러 시작해. 실제 응시 환경과 같은 도구·감독 설정을 사용하지만 문제는 연습용이고, 사전 체험 작업 및 예시 답변은 평가에 반영되지 않아. [공식 · B 2쪽]

7. 가장 흔히 헷갈릴 상황을 미리 판단해 보기

휴대폰만 있으면 PC 웹캠은 없어도 되나?
안 돼. 상세 가이드는 PC의 컴퓨터 웹캠과 휴대폰 Proctor를 각각 준비하도록 안내하고, 휴대폰·태블릿을 PC 웹캠 대신 사용하지 말라고 명시해. [공식 · B 1쪽]
화면 공유를 '브라우저 탭'으로 선택했는데 연결이 안 돼.
탭·창이 아니라 전체 화면을 선택해야 해. 화면 공유가 끊기면 상단 '감독 연결' → '연결 확인'에서 '전체 화면 다시 공유'를 선택해. [공식 · B 1·5쪽]
폰은 연결했는데 녹화가 아직 시작되지 않았어.
연결만으로 본시험 녹화가 시작되지는 않아. '과제 시작'을 누르는 순간 자동 녹화가 시작돼. 연결 상태는 PC에서 확인해. [공식 · B 1~2쪽]
시험 도중 Proctor가 끊겼어.
상단 '감독 연결' → '연결 확인'에서 장치를 재연결해. 휴대폰은 Proctor 앱에서 실제 응시 화면의 연결 QR을 다시 스캔해. 복구 중에도 타이머는 진행되고, 장애 구간은 기록돼. 복구 실패 시 오류 문구·시간을 문제 신고로 남겨. [공식 · B 5쪽]
모니터를 한 대만 켰으니 다른 모니터가 연결되어 있어도 괜찮겠지?
상세 가이드는 2대 이상의 모니터가 감지되면 시작할 수 없다고 설명해. 추가 모니터는 분리하고 전체 화면을 다시 공유하는 게 안전해. [공식 · B 1·5쪽]

8. 실제 규정을 이해했는지 확인하기

아래는 공식 기출이 아닌 학습용 문제야. 답을 선택하면 바로 근거와 설명이 나와.

1. 휴대폰으로 촬영하니까 PC 웹캠은 없어도 된다.

2. PC 웹캠에서는 얼굴 전체뿐 아니라 양쪽 귀도 보여야 한다.

3. 크롬에서 시험 탭만 공유하면 감독 연결이 완료된다.

4. 설치용 QR과 응시 연결용 QR은 같은 QR이다.

5. 과제 시작 버튼을 누르기 전에 신분증을 먼저 보여준다.

6. 사전 체험 문제의 결과와 예시 답변은 평가에 반영되지 않는다.

7. 다운로드·업로드 5Mbps 이상은 필수 합격 커트라인이라고 공식 명시됐다.

8. 주민등록증은 사진과 이름까지 모두 가린 뒤 제시한다.
