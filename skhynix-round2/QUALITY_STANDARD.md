# 제3자 관점의 학습 품질 기준

이 문서는 실제 제3자 평가를 위한 기준이다. 아래 역할 10개는 검토 관점이며 실제 참여한 담당자 10명이 아니다. 자동 검사·브라우저 시뮬레이션은 실제 학습 효과나 독립 패널 평가를 대신하지 않는다.

## 평가 체계

각 관점은 10점이며 두 관찰 기준이 각각 5점이다. 실제 평가자는 충족 5 / 부분 충족 2 / 불충족 0으로 근거를 남긴다. 목표는 평가자별 95/100 이상, 각 관점 7점 이상, 중대 오류 0이다. 평균만 높고 특정 학습자가 실패하는 결과를 목표 달성으로 보지 않는다. 현재 실제 패널은 미실시이므로 그 점수와 인원은 공란으로 둔다.

| 관점 | 확인할 행동 1 | 확인할 행동 2 |
|---|---|---|
| 처음 방문한 학습자 | 서비스의 목적과 실제 가능한 기능을 설명 | 첫 학습과 다음 행동을 찾음 |
| 비개발 직군 | 핵심 용어를 사전 지식 없이 이해 | 코드 작성 없이도 자료의 근거·품질을 판단 |
| 개념을 가르치는 편집자 | 원칙·예시·적용 문제가 연결 | 잘못 일반화할 조건·반례를 구분 |
| 도메인 실무자 | 목표·권한·성공 기준·예외를 발견 | 경험을 검증 가능한 규칙으로 전환 |
| 데이터 검토자 | 중복·결측·분모·경계값을 대조 | 관측 차이와 원인 결론을 분리 |
| 오답을 낸 학습자 | 왜 틀렸는지 확인 | 해당 단계/문항만 다시 풀고 재확인 |
| 근거를 검토하는 독자 | 공식 설명·관찰·추론·가상을 구분 | 원문·날짜·적용 범위와 정정을 확인 |
| 학습을 이어가는 독자 | 읽음과 이해 확인을 구분 | 이전 읽기·풀이·답안을 복원 |
| 모바일·키보드 사용자 | 다섯 크기에서 잘림 없이 탐색 | 키보드·터치로 선택과 본문 이동 |
| 운영·품질 담당자 | 데이터·정답·상태·공유 링크 재현 | Preview를 확인한 동일 소스가 운영됨 |

## 점수와 무관하게 배포를 막는 중대 오류

- 잘못된 계산·정답 또는 원문과 반대되는 핵심 주장을 확정 사실로 표시
- 출처·개인 경험·제품 설명을 하이닉스의 미공개 규칙이나 점수식으로 표현
- 동작하지 않는 AI·실행·평가를 실제 기능이라고 표시
- 주요 자료 누락·원본 삭제·학습 상태 파손·핵심 메뉴 접근 불가
- 실제로 하지 않은 테스트·전문가 평가·학습 효과 검증을 완료라고 보고

## 학습자가 실제로 해야 할 일

1. 개념: 목표·자료·판단·AI 위임·검증·설명을 구분한다.
2. 예시: 완성된 계산을 읽고 분모·조건·한계를 설명한다.
3. 적용: 가상 원자료에서 8개 판단을 선택하고 틀리면 피드백 후 다시 시도한다.
4. 전이: 다른 숫자에서도 같은 원칙을 적용한다.
5. 독립 수행: 다른 과제를 허용된 도구로 풀고 자신의 결과물을 설명한다. 이 단계는 선택형 문제 완료만으로 확인되지 않는다.

## 검토와 배포 원칙

reports/learner-journeys.json의 10개 경로를 작업자가 가정한 학습자로 수행한다. 실제 사람의 관찰은 별도 상태로 남긴다. 내용에는 주장→가정→대안 설명→반례→행동→검증을 연결한다. UI의 읽음 기록은 숙련도 점수가 아니다. 교육 연구는 설계 근거이며 이 서비스의 효과를 실험해 입증한 자료로 표현하지 않는다.
