## 각 문제를 제작할 때 추가할 기록

- 제작 일시·기준 문서 버전
- 문항 ID / 유형 / 난도 / 목표시간 / 독립 지문 / 발문 / 5개 선택지
- 정답 하나임을 입증하는 지문 근거
- 오답 각각이 왜 틀렸는지 판단 근거
- 실제 원전(서지·URL·확인일)과 AI 기술 용어의 의미 확인
- 반례·조건누락·정답중복 검토 결과
- 사용자 선택 / 소요시간(알면) / 오답유형 / 재학습 항목
- 누적 상태: PLANNED → DRAFT → REVIEWED → RELEASED. 사용자가 풀기 전 정답은 사용자 노출 금지.

## 재개 절차

1. 먼저 [PLAN_20.md](./PLAN_20.md)와 이 파일을 읽는다.
2. 사용자가 지정한 번호의 문제 하나만 작성한다(기본 Q01).
3. 이미 RELEASED된 문항이면 중복 생성하지 않고 사용자 요청에 맞춰 풀이·개선만 수행한다.
4. 지문·선택지 생성 후 별도 `questions/QXX.md`와 본 장부를 GitHub에 갱신한다.
5. GitHub 커밋 성공 여부를 확인한 뒤만 저장 완료라고 말한다.
6. 사용자가 지시하지 않으면 Vercel 배포·20개 일괄 생성은 하지 않는다.
