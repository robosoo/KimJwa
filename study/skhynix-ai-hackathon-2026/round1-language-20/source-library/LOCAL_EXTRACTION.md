# 공개 시험 PDF에서 본인 기기로 텍스트 추출하기

> 시험 원문의 저작권을 존중하면서 **개인 학습용 텍스트**를 만드는 방법. GitHub 공개 저장소에 원문 지문·선택지 전문을 재업로드하는 방법이 아니다.

## 먼저 읽기

- PDF 다운로드·열람이 가능하다는 사실만으로 **문제 전문의 GitHub 재배포 권한이 생기지는 않는다.**
- 수능·모의평가 PDF에는 한국교육과정평가원 저작권 문구가 명시되어 있다.
- PSAT 출처별 이용 조건도 개별 확인해야 한다.
- 페이지별 텍스트를 추출하더라도 **표, 수식, 그림, 선지 구분, 순서 등이 누락되거나 흐트러질 수 있다.**
- GitHub의 [VERIFIED_REAL_QUESTIONS.md](./VERIFIED_REAL_QUESTIONS.md)에는 15개 문제의 원문 링크·문항번호·주제·풀이 유형만 저장한다.

## 2. 개인 컴퓨터에서 PDF의 텍스트를 추출하는 예시

Python의 PyMuPDF를 설치하거나, Poppler의 `pdftotext`를 사용할 수 있다. 아래 예시는 **다운로드 받은 사용자의 로컬 파일만** 다룬다.

```bash
# Poppler가 설치된 로컬 컴퓨터에서 실행
pdftotext -layout -f 1 -l 1 "2026_09_korean.pdf" "local_2026_09_q01_03.txt"
pdftotext -layout -f 4 -l 5 "2025_csat_korean.pdf" "local_2025_csat_q10_13.txt"
```

- 원본 PDF를 공식 페이지에서 **사용자가 직접 내려받은 후** 실행한다.
- 2025 수능 13번은 그림과 흐름도가 핵심이다. 텍스트만 보고 채점하지 말고 반드시 PDF 5쪽을 함께 본다.
- 문단별 구분, 숫자·수식·특수 기호, 문제와 보기가 올바른 순서인지 원본과 대조한다.
- 추출 텍스트가 생성되더라도 공개 GitHub 커밋 대상에서 제외한다.
- iPad만 이용할 경우 위 GitHub 자료실의 '문제 열기' 링크로 PDF 원문을 열어 바로 풀이하는 방법이 더 간단하다.

## 3. 향후 추가 수집 기준

1. 원문을 공식 또는 신뢰 가능한 출처에서 확인.
2. **정확한 문항번호·책형·시험 날짜** 확인.
3. AI·자율 로봇·AI 활용 판단 등 주제가 실제로 일치하는지 점검.
4. 원문 링크, 문제 풀이 형식, 난도 분석, 저작권 안내만 GitHub에 수록.
5. 적법한 재배포 허락이 명확히 확인된 경우에만 해당 라이선스 조건을 명시해 전문 보관을 별도 검토.
