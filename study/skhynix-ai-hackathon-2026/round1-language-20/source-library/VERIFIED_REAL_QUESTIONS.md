- **묶음 A · AI 시대의 읽기 (EX-001~003):** 2026학년도 9월 모평 국어 1~3번. PDF 1쪽. 한 지문에서 정보 확인→과정 추론→새 사례 적용으로 심화된다.

### 문제와 출처의 실제 확인 수준

- EX-001~003: EBSi에 게시된 평가원 국어 문제지 PDF 첫째 쪽과 EBS 공식 정답·해설 PDF 첫째 쪽을 확인. 문제지 PDF 하단에 저작권 표시.
- EX-004~007: EBSi 2025학년도 수능 국어 홀수형 PDF 4·5쪽, EBS 공식 정답·해설 PDF의 정답표를 확인. 13번에는 이미지·도식이 포함돼 있으므로 **텍스트 변환만으로는 풀이 불가**.
- EX-008~015: 출제 연도·책형·문항번호와 논지·문제 유형을 실제 PSAT 해설 페이지에서 검증. **PSAT 관련 링크 중 문제 전문은 제3자 해설 페이지**이며, 공식 시험지/정답 다운로드는 [기출 연도별 목록](https://psat-bamdori.tistory.com/1406)과 [공공데이터 PSAT 안내](https://www.data.go.kr/data/15060913/fileData.do)에서 별도 확인 가능. 비공식 해설을 공식 정답으로 표시하지 않는다.

### 활용 방법

1. 위 표의 **문제 열기**를 누르고 실제 문제지에서 해당 번호와 지문을 읽는다.
2. 지문 → 발문 → 선택지를 스스로 풀되, 정답은 먼저 열지 않는다.
3. 정답 확인 후 **무엇을 놓쳤는지** 짧게 기록한다: 조건, 단서, 예외, 판단 범위, 용어 구분.
4. 원문의 전체 텍스트를 본인 기기에서 개인 학습 목적으로 추출하려면 [LOCAL_EXTRACTION.md](./LOCAL_EXTRACTION.md)를 참고한다. 공개 저장소 재업로드 전에는 별도 저작권·재배포 허락이 필요하다.
