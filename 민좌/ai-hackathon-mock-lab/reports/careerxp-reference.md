# CareerXP 공개 안내 검토

2026-10-11 공개 페이지 https://careerxp.work/ax/assessment 를 HTTP GET으로 읽었다. 검색 도구는 접근에 실패했으나 공개 HTML은 확보했다. 로그인·결제·유료 회차에는 접근하지 않았다.

참고한 원리: AI 기초 지식 객관식/OX, 업무 자료를 선택해 조건에 맞는 답 찾기, 목표·자료·조건·답 형식 명시, 원자료 대조와 재계산, 6단계 해설과 과정 돌아보기.

공개 안내의 60분·세트별 10회·1,000자·20,000토큰·30초 간격은 CareerXP 상품의 규칙이다. 실제 SK하이닉스 예선의 확정 규칙으로 채택하지 않았다. 사이트는 자율 경과시간과 질문 10회 자기기록 목표를 제공한다. 외부 ChatGPT 이용 횟수를 통제하거나 읽을 수는 없다.

사용자 제공 5문항은 기존 사진 검증 문항을 교체하고 나머지 4문항을 추가했다. 5지선다·OX를 그대로 보존하고 상세 해설을 별도로 작성했다. 유료 문제·데이터 파일·코드·디자인을 복제하지 않았다. 신규 환불·공급사 데이터는 독립 창작이다.
