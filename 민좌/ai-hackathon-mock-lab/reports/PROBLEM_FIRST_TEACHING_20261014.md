# 문제 이해부터 시작하는 공개체험 수업

사용자의 요구에 맞춰 다섯 과제 모두 문제를 처음 읽는 사람의 순서로 설명한다.

1. 먼저 문제 상황과 실제로 묻는 것을 자연어로 설명한다.
2. 첨부 자료의 종류와 역할을 연결하고 전체 파일명·형식·토큰도 확인할 수 있게 한다.
3. 그러면 무엇부터 확인해야 하는지, 사람이 정할 기준과 AI 반복 작업을 설명한다.
4. 질문 횟수·첨부 토큰 배분과 그 이유를 설명한다.
5. 실제 첫 질문을 원문 그대로 보여주며 오류가 있었던 지시도 경고한다.
6. AI 답변에서 사람이 확인할 근거와 오류 신호를 설명한다.
7. 기존 상세 회차·문항별 풀이·응답·최종 답안으로 이어진다.

자료: 보존된 공식 체험 지문 스냅샷, 실제 첨부 목록, 실제 질문·응답 및 기존 검증 기록. 원문을 확인하지 못한 새 문제나 새 시험 규칙을 만들지 않았다.

실제 대화와 제출 답안은 수정하지 않았다. 특히 리터러시 첫 질문의 잘못된 Core 30% 지시는 그대로 보존하고 그 앞에 교정 설명을 붙였다. 새로운 설명은 교재용 해설이며 인간 단독 수행 시간이나 개선 템플릿의 재시험 결과로 표현하지 않는다.

통합 PDF 111쪽(새 수업71+기존 식품·화장품40). 새 71쪽의 축소 이미지와 새 도입부 상세 페이지를 시각 검수했다. 기존 구조·편집·33개 수치 검사 통과. Vercel 배포는 READY다. 이번 변경의 최종 브라우저 확인은 자동 승인 검토의 사용 한도 초과로 거절됐다. 진행 중이던 HTTP 검사도 네트워크 정책으로 차단돼 완료하지 못했다. 이를 우회하지 않았고 인터랙션 검증 통과로 기록하지 않는다.


## 기존 작업 보존 확인

배포용 index.html의 JSON을 독립 파싱해 64문항·8실습·26개념과 공개체험 5과제 번들을 확인했다. 기존 식품·화장품 및 네 과제의 소스·실제 세션·질문은 남아 있다. 문제 접근 설명을 기존 기록 앞에 추가했다. 사용자에게 기존 내용이 화면에서 보이지 않는다고 보고받았지만 실제 화면 원인은 브라우저 제한으로 확인하지 못했다.
