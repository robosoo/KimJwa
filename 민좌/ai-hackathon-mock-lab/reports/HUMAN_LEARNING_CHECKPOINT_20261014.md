- 구독 비용: 4문항 400/400. 7질문, 3회 잔여. 파일 17개, 고유 토큰 43,720.

- 주문 조회 API: 아직 실제 풀이 전.

## 교재 편집 기준

초점은 사람이 어디까지 직접 확인하고 어떻게 문제를 풀 수 있는가이다. 문제를 처음 보았을 때 확인할 문구, 파일 선택 이유, AI에 맡기는 반복작업, 원문에서 다시 확인하는 위치, 추가 질문을 써야 할 때, 사람이 계산기로 바로 고칠 수 있는 오류를 설명한다. 실제로 입력한 프롬프트와 개선용 미실험 템플릿은 구분한다. 외부 AI의 일괄 PDF 분석을 사람이 혼자 수행한 검증으로 표현하지 않는다. 보지 못한 원문과 검증하지 않은 기능은 확인 불가로 남긴다.

## 구독 과제에서 실제 발견한 오류

1. 실제 보기④ 문서 요약이 있는데 AI는 없다고 주장하며③으로 오답. 팀 보고서의 사용 기능과 정책 기능표 대조로 수정.
2. 글로벌사업팀 사용인원을12명으로 오집계. 화면1쪽8명+2쪽6명=14명, 유휴4→2명으로 수정.
3. 영업운영팀 계약18개를 사용인원18명으로 오인. 화면1쪽8명+2쪽8명=16명, 유휴2명 확인.
4. 개별 금액130+160+100+40+40을430으로 잘못 더함. 사람이 검산해470으로 입력, 실제 정답 확인.

저장된 회차별 원문 응답은 오류와 모순을 포함한 실제 출력이며 정답 해설로 읽으면 안 된다. 최종 답과 수정 근거를 함께 확인해야 한다. 서술형 원자료에 있는 개인식별정보는 공개 교재에 재게시하지 않는다.


## 두 번째 저장 시점

리터러시: 제출·통과 팝업 확인, 수치 점수는 -/100. 전송5회 중 일시오류1회는 차감되지 않아 실제4회 사용·6회 잔여. 최종입력3894자. 가중평균은 화면14행을 전사한 별도 산술 검산으로 보완했으며 내장AI만의 검증 성과라고 주장하지 않는다.

주문 API: 실제 질문3회 전송, 최종 초안 검토 중. 기존코드 LIMIT20과 스펙의 파라미터표를 구분한 검증 과정을 기록했다.

네 과제의 사람이 직접 볼 지점·파일선택 이유·실제 오류·개선 템플릿은 data/practical-human-lessons.json에 저장했다. 웹/PDF 연결과 최종 검증은 아직 진행 중이다.
