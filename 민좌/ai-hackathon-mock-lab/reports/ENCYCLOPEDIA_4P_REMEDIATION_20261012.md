# 2026-10-12 · AI 개념 백과사전 + 4P 내재화 시스템 개선 실행 기록

## 사용자 지시 및 설계 원칙
- 사용자가 요구한 학습 분리: **개념 공부는 반도체 비종속의 범용 AI 위키**, **4P는 먼저 보편적인 개념 이론 → 8개 일반 상황 구별 → 마지막에 반도체 6개 사례**.
- 이전 가상 전문가 100인 리뷰에서 고른 해결책: 20자 작성·모범 해설 열람과 실제 판단 역량을 분리하고, 일부러 틀린 AI 출력의 검증, 후속 프롬프트 수정, 숫자·조건이 변경된 변형 문제를 적용.
- 4P의 철학적 기준은 프로그래머스의 범용 AX 교육 프레임워크이며 특정 SK하이닉스 예선의 공식 채점 구조라고 주장하지 않는다.
- 사례·AI 출력은 모두 가상이며 실제 반도체 회사 로그·사양·고객 자료를 수집하거나 업로드하지 않는다.

## 학습 효과 측정 시 주의
- **학습(해설 비교)**: 4P 단계마다 20자 이상 자신의 판단을 기록하고 예시를 확인한다. 의미상의 정오 자동채점이 아니다.
- **실전 훈련(독립 진단)**: 검증 단계에서 의도적으로 틀린 AI 문장을 제시하고 정확한 문제를 지목, 이후 수정 요청문을 직접 작성. 새로운 수치·적용 규칙에 대한 선택도 실행.
- **최초 시도 정답**: 최초 객관식 선택 기록은 수정 후 재제출해도 보존. 단, 수치/규칙 선택의 정답을 검증한 것이지 4P 종합 역량 또는 공식 합격점수는 아님.
- **개인정보/보안**: 학습 입력은 브라우저 localStorage와 JSON 백업에 남는다. 실제 회사·고객·개인 식별·비밀 자료를 입력하지 않아야 한다.
- **하위 호환성**: 문항 ID, 문제 64개, 개념 26개, 기존 AI 활용 실습 8개 및 기존 4P 사례별 기록의 의미를 유지한다.

## 확인 방법
1. `https://skhynix-ai-hackathon-quiz.vercel.app/` 열기 → 상단 `개념 공부` → 개념을 검색하고 정의·원리·한계·일상 사례 확인.
2. 상단 `4P 사고법 훈련` → 기본 개념 카드 4개 및 심화 설명 → 일상 상황 8개 구별.
3. 반도체 6사례 중 한 사례 선택 → Plan→Prompt→Probe→Protect 답변 작성→각 해설 비교.
4. 내부 가상 AI 오류 보고서를 검토·수정 → 바뀐 조건의 과제 답 선택 → 추가 독립 진단 2개를 각각 풀고 최초 시도 결과 비교.
5. 브라우저 새로고침 → 각 진도·독립진단 기록 유지 검증. 다른 기기로 옮길 때 학습 기록 내보내기/가져오기.

## 공식 출처 및 신뢰 경계
- 프로그래머스 기업 AX 교육 4P: https://programmers.co.kr/b2b-education (2026-10-12 확인).
- 프로그래머스 AI 역량평가: https://programmers.co.kr/ai-assessment.
- 상세 AI 위키 항목별 OpenAI/Google/Anthropic/NIST 등의 공식 개념 문서는 `data/concept-lessons.json`의 sources에 연결.
- 근본적 한계: 실제 인간 평가자 100명을 섭외하지 않았으며 이전 리뷰는 역할 기반 AI 시뮬레이션이다. 위 기능은 이에 대한 구현이지 학습 효과의 실증 증거가 아니다. 실물 iPad와 VoiceOver는 실제 기기 사용 검증이 필요하다.

## 미완료/추가 검증 과제
- 실제 iPad Safari 키보드·스크롤·VoiceOver 실기기 검증.
