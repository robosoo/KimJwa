# 추가 제공 자료의 반영 범위

사용자 제공 세미나 요약과 예선 준비 영상 요약을 2026-10-11에 받음. 원본 영상 URL과 발언 확인자료는 제공되지 않았으므로 모든 세부 주장에 대해 공식 확인을 완료한 자료로 취급하지 않음.

반영: 아는가·해내는가·재현하는가 관점, 문제 정의·AI 협업·오류 검증 및 개선·책임 관리의 4개 자가점검축, 데이터 선택→프롬프트→검증→객관식 결과 선택, 6단계 과정 기록. 별도 전문/코딩 시험으로 범위를 확장하지 않음.

공식 규칙으로 사용하지 않음: 5등급, 30~120분, 체험 40분, 모의시험 60분/8문항, AI 질문 10회, 응시권 가격, 리포트 발송일, 기업별 실제 시행 상세.

사용자 환불 예시 산술: 14,377,000-113×3,000=14,038,000원. 산술은 재검산함. 전체 원자료가 없어 대상 113건·총액의 집계 적합성은 미확인. 사이트 실습은 이를 복제하지 않고 별도 소규모 자작 원자료로 출제.

질문 10회는 선택 가능한 자기기록 연습 제한이며 외부 ChatGPT 실제 호출을 감시·차단하지 않음. 자동 과정 점수/공식 합격 확률을 산출하지 않음.
