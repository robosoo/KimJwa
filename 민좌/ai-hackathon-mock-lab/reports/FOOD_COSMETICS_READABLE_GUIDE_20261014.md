# 식품·화장품 실전 풀이 해설

기존 28쪽 교재의 긴 영문 파일명과 코드 나열을 폴더별 선택 안내로 바꿨다. 실제 실행 기록과 사람이 읽는 설명을 함께 보존한다.

## 화면

- `/food-cosmetics-guide.html`: 풀이 순서, 실제 질문 9회, 파일·토큰 선택 연습, 정답·검증.
- 각 회차: 목적 설명 → 폴더·파일 선택 → 첨부 합계 → 실제 프롬프트 복사 → AI 응답의 요점과 전문 → 사람의 검증·기록.
- 긴 파일명은 펼쳐 보고, 평소에는 폴더·앞 번호·한국어 설명으로 찾는다. 한국어 상품명은 공식 상품명의 대체 표기가 아닌 설명이다.
- 토큰 연습은 파일 선택 상태에 따라 실제 목록의 표시 토큰을 합산한다. 공식 사이트 업로드나 AI 호출 기능은 없다.
- 강의서 PDF: 40쪽, 장별 책갈피와 회차별 첨부 안내. 실제 질문·응답 전문 보존.

## 근거와 한계

- 공식 공개 체험 실제 4문항 모두 100/100, 총 400점. 9회 사용·1회 잔여.
- 파일 47개(규정 2 + 상품 45), 최초 첨부 합계 114,857토큰.
- 질문 입력 1,000자, 파일 첨부 20,000토큰은 별도 UI 제한.
- 원래 실행 질문·응답 9쌍을 구조화 기록과 대조했다.
- 상품 6묶음에 중복·누락 없이 45개가 포함되는지와 회차별 토큰을 확인했다.
- 8회 운영안은 기능 진단 1회를 생략하는 제안이며 별도 8회 재응시 결과가 아니다.
- 인간 단독 응시 실험이 아니다. 보조 AI의 화면 조작·719자 기준문 편집과 규정 뷰어 검증을 포함한다.
- 실제 상품 PDF 원문은 재배포하지 않는다. 공식 체험에서 확인해야 한다.
- 전체 Context Window 크기 및 서버 내부 파일 보관 방식은 확인 불가다.
