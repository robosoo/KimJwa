# 2026-10-12 · AI 위키 및 4P 내재화 개선 — 변경 기록

## 사용자 요구
1. AI 개념 설명은 특정 업계 사례 중심이 아니라 **중립적인 백과사전** 방식으로 제공한다.
2. 4P도 먼저 **개념의 정의·필요성·방법·일상 예시·오해**를 충분히 가르친 후 **반도체 적용 문제**로 전환한다.
3. 100인 가상 전문가 시뮬레이션 보고서의 실제 코드 기반 우선순위 개선을 반영한다. 보고서는 실제 인간 검토가 아니며 학습성과를 입증하지 않는다.

## 구현과 데이터
- `data/concept-lessons.json`: 26개 항목 모두 `wiki` 추가. 정의 / 작동 원리 / 개념의 경계·한계 / 보편 예시 / 확인사항 / 연계 항목. 기존 쉬운 풀이, 개념 예제·공식 출처·문제 링크는 보존한다. 신규 설명은 반도체 중심이 아닌 범용 AI 문서다.
- `src/index.html`의 '개념 공부': AI 개념 위키 라벨 및 사전식 위계로 화면 전환. 목록 검색은 사전의 정의·원리·경계까지 포함. 관련 항목 이동 가능.
- `data/four-p-guide.json`에 4개 `dimensions[].encyclopedia` 추가: 정의 / 필요한 이유 / 실천 절차 / 일상 사례 / 남길 산출물 / 오해 / 자기점검 질문. 개념 카드의 비교 예시는 반도체 대신 일반 사례로 변경.
- 4P 흐름: **(1) 4P 개념 사전 → (2) 8개 구별 퀴즈 → (3) DRAM/HBM 등 6개 사례 4단계 직접 작성 → (4) 가상의 잘못된 AI 답변 탐지 + 후속 프롬프트 수정 → (5) 바뀐 숫자·조건의 독립 전이 검증**.
- `data/four-p-guide.json`의 `cases[].drill` 6개: **잘못된 AI 초안, 오류 검증 객관식 3지선다, 반드시 직접 입력하는 수정 요청, 오류 해설, 새로운 조건의 재판정**. 실제 모델 API 호출 결과가 아닌 의도적으로 설계한 가상 응답.
- `src/index.html`: 4P 단계별 작성 완료와 객관식 판정 성공을 서로 다른 지표로 분리. 마지막 4P 개념 응용 뒤 새로 추가된 오답 검증과 변형 과제를 제출하면 다음 사례로 이동. 과거 학습 기록 불러오기 호환. 입력값은 현재 기기 브라우저에만 보존.
- 학습자의 수정 프롬프트는 **내용 자동 채점하지 않으며**, 20자 이상 제출 요건 뒤 예시와 비교한다. '독립 수행 통과'는 두 객관식의 정답 여부를 뜻하며 실제 종합 역량 인증이 아니다.
- 기존 64개 1차 문제, 개념 26개, AI 실습 8개, 비공식 자료 출처/기존 과제는 삭제하지 않았다.

## 반영한 가상 평가 피드백
- [반영] P0-1: 6개 가상 AI 오답 출력의 Probe 역검증.
- [반영] P0-2: 4P 해설 확인과 독립 객관식/전이 검증을 별도 기록.
- [반영] P0-3: 1차 AI 오류를 보고 후속 Prompt 재작성하는 훈련.
- [반영] P0-4: 학습자 기록과 실습에 회사·고객·NDA·개인정보 원문 사용 금지 안내.
- [부분 반영] P1-1: 6개 새 숫자·조건 변형 검증, 향후 사례·난이도 확장 가능.
- [부분 반영] P1-2: 4P 별도 이론·증거 형태를 설명하나 자유서술 자동 의미 채점은 없음.
- [미반영·계획] 48시간 후 복습 알림, 실제 API 연결, 전체 iPad Safari 실기기·VoiceOver 테스트, AI 평가자의 의미 정확성 자동 판단, 실험 기반 학습 효과 수집은 아직 없음.
- [주의] AI 개념 문서는 교재형 독립 해설이고 각 항목에 공식 문서 참고 링크가 있다. 모든 위키 문장을 전문가 동료 검토한 사실은 없다.
