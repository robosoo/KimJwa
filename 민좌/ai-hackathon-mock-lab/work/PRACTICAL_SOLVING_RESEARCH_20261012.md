# SK하이닉스 AI 해커톤 1차 — AI 실전 문제 풀이법 조사와 구현 기준
작성: 2026-10-12. 상태: 공개 근거 조사 완료 / 비공식 학습 전략. 문제 원문 복제 없음.

## 1. 공식 확인 사실 vs 추론 vs 확인 필요

### 공식 확인
- SK하이닉스 2026 AI 해커톤 공식: https://skhynix-hackathon.com/ai-2026
  - 1차 예선 10/17~18 중 하루, AI 기초 지식 및 활용 역량 검증.
  - 2차 예선 10/31~11/1 중 하루, AI Native 역량 검증. 코엑스 본선 11/11.
- SK하이닉스 Talent Hub 공식: https://talent.skhynix.com/hub/ko/company/story/237
  - 온라인 예선은 AI 기본 활용 역량·AI 리터러시, 문제 정의·AI 활용·결과 검증 과정을 종합 검토하며 Cofa-Probe 등 다양한 도구를 사용한다고 안내.
- 프로그래머스 AI 역량평가 소개: https://programmers.co.kr/ai-assessment
  - 지식평가: AI 리터러시 객·주관식. 활용평가: 전 직군 실무 과제형·프롬프팅 활용. 전문평가: 통합 전문·개발자 평가.
  - AI 사용 로그·프롬프트 수정·중간 개선 과정, 최종 산출물을 별도 평가한다는 서비스 설명.
- 프로그래머스 AX 교육 공식: https://programmers.co.kr/b2b-education
  - 4P 항목: Plan 문제 정의 / Prompt AI 협업 / Probe 결과 검증 / Protect 책임 관리.
  - 결과와 과정 모두 평가한다는 서비스 소개. 단, 해당 4P 세부 항목은 프로그래머스의 일반 평가 체계이며 SK하이닉스 예선 공식 배점이라는 증거는 없음.
- 프로그래머스 응시 환경 체험: https://programmers.co.kr/ai-assessment/preview
  - 사이트 안내 공개. 유료 문항이나 비공개 문항, 실제 SK 시험 문항 원문은 사용하지 않음.
- Anthropic 공식 프롬프트 가이드: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/prompt-templates-and-variables
  - 명확한 지시·맥락·출력 형식·적절한 예시, 다양한 자료의 구조화, 성공 기준과 교차 검증을 권장.

### 검증되지 않은 것
- 2026 SK하이닉스 **1차 실제 문제 개수, 시험 시간, 배점, AI 도구 허용 범위, 4P의 실제 채점 가중치, 질문 회수 제한, 정확한 시험 UI** 는 공개 정보로 확정 불가.
- 1차에서 실습 과제를 실제로 제출하게 되는지, 객관식만 나오는지도 확정 불가.
- 2차 AI Native 평가 또는 Cofa-Probe 실습이 프로그래머스의 모든 기능과 동일하다고 주장하면 안 됨.
- 공개 자료에서 4번째 P를 Project로 표기하는 마케팅 게시물과 Protect로 표기하는 교육 공식 페이지가 있어, 본 안내에서는 현재 교육 페이지의 **Protect**를 사용하되 SK 공식 평가 체계로 단정하지 않는다.

## 2. 실전에서 재현 가능한 풀이 6단계 (독립 작성)

| 단계 | 사람의 판단 | AI에게 맡길 것 | 증거/실패 기준 |
|---|---|---|---|
| 1. 문제 정의 | 최종 답·단위·적용 범위·제한 조건 정의 | 질문에서 목표/조건/모호함 추출 보조 | 요구사항 누락 여부 |
| 2. 규칙 해석 | 버전·기간·경계(≤, <, 포함 여부)·우선순위 | 규칙표·제외 조건 정리 | 구판/누락/충돌 |
| 3. 자료 선별 | 최신본·원본·유효 표본·필요 자료 선별 | 파일 목차/열 정리, 결측·중복 후보 탐색 | 사용한 자료명·출처·버전 |
| 4. AI와 1차 풀이 | 작업을 분해해 프롬프트와 형식 지정 | 조건표, 중간 계산, 근거 표 생성 | AI 출력 초안·산식 |
| 5. 반증·독립 검증 | 원자료 직접 재집계, 오류·반례 검사 | 별도 검산 요청과 실패 케이스 제시 | 불일치 기록, 수정 근거 |
| 6. 제출/책임 | 요구 형식과 검증 상태 점검 | 보고서 요약·미확인 항목 정리 | 사실/추론/확인 필요 + 데이터 유출 방지 |

## 3. 1차 객관식과 AI 활용 과제를 구분해 대비

- 지식형(1차 범위): 정의 암기가 아니라 상황의 조건을 읽고 잘못된 행동·오해를 구분. 문제 지문 → 적용 원칙 → 선택지의 필수 조건 누락 → 정답 근거와 오답 이유.
- 자료 활용형(1차 가능성 대비): 목적·규칙·필요 자료 → AI 초안 → 데이터 재검산 → 제출. 실제 1차에 자료 활용형이 몇 문항 나오는지는 확인 불가.
- AI Native/에이전트형(2차): 별도 범위. 현행 1차 문제집을 코딩·자동화 에이전트 개발 문제로 바꾸지 않음.

## 4. 프롬프트 설계 공통 구조
상황/역할 → 목표 → 입력 데이터 → 적용 기간 및 규칙 → 금지(추측/원인 단정) → 요구 출력(행별 판단, 산식, 출처) → 검증(역경계·결측·대조군·교차 확인).
'AI가 100% 맞는다', '사고 과정을 모두 출력하라', '근거 없는 3가지 원인을 반드시 만들라' 같은 요청은 배제.
생각의 내적 과정을 요청하기보다 판단 근거와 검증 가능한 중간 결과를 요구.

## 5. 기존 8개 실습과 연결 기준
- R1-01: 8,000행과 고유 wafer 7,720의 **집계 단위 차이**. 결측 140, 중복, 전일 자료 부재.
- R1-02: 라인 A/B의 제품 종류가 다른 **교란변수**; 상관과 인과 구분.
- R1-03: 정확도 98.2%와 Recall 60% **비대칭 오류비용**, 독립 계산.
- R1-04: 입력 로그·조건이 없는 '원인 3개' 요청의 위험, 질문 재설계.
- R1-05: 2025 v1.1 3.6V vs 2026 v2.0 3.3V **해당 HW 리비전 적용 확인**.
- R1-06: 외부 문서의 API키 유출 지시 = **간접 프롬프트 인젝션**, 신뢰 경계.
- R1-U01: 환불 정책 최신본·14일 포함·분기·사유별 공제·수정본 우선·실제 집계(191,000원).
- R1-U02: 납기≤7일·불량≤1.0% **동시 충족** 후 100개 총비용 최소(A, 205,000원).

## 6. 구현/검증 조건
- 사이트 새 '실전 풀이법' 탭에 6단계 교재와 실제 8개 과제별 1차/검산/수정 프롬프트 삽입.
- 모범 정답을 첫 화면에 노출하지 않고 열어 보는 방식으로 구성. 실제 정답 확정과 증거 구분.
- 8개 기존 실습, 64개 문제, 26개념, 학습자별 기존 기록에 손상 없어야 함.
- 사이트 자체 AI 호출 없음. 프롬프트 복사 후 ChatGPT 실행. 로컬 데이터 또는 가상 실습 데이터 외 민감 원자료 업로드 금지.
- Chromium/WebKit PC·iPad 규격 테스트 및 공개 URL HTTP 확인. 자동 검사와 실제 iPad 실기기 사용 테스트를 구분.
