## 0. 사용자 요청의 최종 결정 — 절대 흐리지 말 것
- 목적: **2026 SK하이닉스 AI 해커톤 1차 예선(10월 17~18일) 준비**. 시험 운영 및 문항 스타일의 기준은 **프로그래머스 AI 역량평가 비개발 직군용 체험문항 1~10번**이다.
- 범위는 **AI 기초 지식 + AI 활용 역량**만. 2차 AI Native, 일반 코딩테스트, 개발자용 API 명세, Claude API 오류코드 암기, 인프라 구현·프로토콜 지식 자체를 묻는 문제는 시험에서 제외. RAG, API 데이터 누락, 설명가능한 AI 같은 기술어는 *현업 판단의 배경*으로만 쓰고 도구 구현법·코드 작성 능력은 평가하지 않는다.
- 현업이 겪는 **레거시 업무, 여러 버전의 문서, 계산 오류, 개인정보, 저작권, 결측·중복 데이터, 비교/검산, 출처 충돌, 편향, 설명가능성, 모델 한계, AI 산출물 검증** 중심.
- 문제 글은 프로그래머스처럼 **업무 시나리오 지문 → 상황/문제/제약 → 명확한 판단 질문 → 그럴듯한 4지선다 또는 O/X**. 특정 이론 이름만 암기하는 한줄짜리 문항은 금지.
- **문제집**처럼 각 문항 하단에서 **정답·상세 해설 바로 보기**. 정답의 근거, 핵심 개념 교과서식 설명, 오답 3개 **각각** 왜 아닌지, 업무 검증 절차, 흔한 함정, 추가 학습 팁, 출처를 표시. 선택 전 정답 확인도 허용하되 ‘해설 봄’ 표기.
- 문제 수 늘리기가 아니라 **문항 품질이 우선**. 나쁜 기존 문항은 삭제/대체/상황형 재작성. 변경 전 데이터는 무조건 유지. 중간마다 GitHub 커밋하고 완수할 때 Vercel 사이트까지 정상 배포·검증.
- 사용자와 동행자 각각 **iPad Safari**에서 문제를 풀 수 있고, 로그인/다운로드 없이 사이트 사용. AI 사용 실습은 개별 **ChatGPT Free/Plus 계정**으로 외부 ChatGPT에서 대화하며 프롬프트 복사/붙여넣기, 결과 수동 회수; 개인 ChatGPT 로그인만으로 사이트 내부 API를 직접 호출할 수 있다고 거짓말하지 말 것. 별도 유료 API는 기본 비활성화.
- SK하이닉스/프로그래머스와 공식 제휴/실제 기출 동일/시간 제한/채점 가중치가 확인되지 않으면 주장 금지. 모든 객관식·모의과제는 비공식 학습용.

## 5. Work의 목표 산출물 — ‘고품질 1차 전용 문제집’
1. **현행 문제 전수 감사**: 90개와 별도 AISCORE 8문항, 12과제 및 PDF 유형표를 비교. 항목별 ID/핵심 개념/업무 시나리오 여부/개발자 전용 여부/오답 설득력/해설 품질/정답 진위/공식 출처를 표로 저장(`reports/round1-audit.csv`). ‘유지/재작성/제외’를 모두 명시.
2. **1차 전용 새 문제은행**: `data/round1-question-bank.json` 등 별도 **독립형 JSON**으로 생성. 시험 범위 밖 문항은 메인 UI에서 아예 숨기되 GitHub 원본은 보존. 기존 90을 억지로 유지할 필요 없이 **품질 합격 문항만 공개**. 필요시 20문항 세트를 먼저 완성한 뒤 단계적으로 확장.
3. **프로그램머스 스타일 지문/4지선다**: 모든 공개 문항에 `id, topic, scenario, question, choices[4], answerIndex, concept, reasoning, wrongReasons[4], verification, pitfall, sourceType, sourceUrl, QAStatus` 저장. 4개 선택지 모두 해당 시나리오에서 타당해 보일 정도로 구성하되 하나만 최적. 너무 쉬운 '항상/절대/무조건' 함정 반복 금지.
4. **문제별 공부 모드**: 선택 → 바로 채점 → 상세 개념 설명과 보기별 이유 → 출처/검증법. 문제집처럼 긴 지문과 표를 읽기 좋게. 색상/정렬/iPad Safari 가독성 확인.
5. **AI 활용 실습**: 문제 정의→원자료/버전 선택→AI 질문→검산·반례→결과 제출. 자유서술형은 1차 범위에 부합하는 것만 유지; 2차 AI Native용 내용은 *별도 아카이브*로 이동.
6. **반복 가능한 검사**: 중복(숫자 2.5%와 25%를 같은 값 취급하지 않음), 구조/정답 인덱스, 단일 정답성, 개념적 타당성, 설명의 출처 신뢰도, 답안 누출/해설 전 표시, 보기 편향, 수치 Python 독립검산, 사용자 선택/오답저장/타이머/갱신의 회귀 테스트. **구조 검사 통과와 지식/해설 검증 완료는 구분**.
7. **배포 및 인수인계**: GitHub에 원문 보존/신규 JSON/검사 결과/이 문서 갱신/개별 커밋. Vercel 별도 preview→실행 테스트→production. 실제 https://skhynix-ai-hackathon-quiz.vercel.app/ 의 변화를 검증. 자동 연동 아니면 직접 deploy. 완료 범위·미검증 범위 보고.

## 6. 문항 출제 가이드 — 우선순위
**A(최고):** AI가 만든 답의 숫자 검증(단위·결측·중복·분모·시간대·버전), 개인정보·저작권, 사내 표준/레거시 문서 RAG 정합, 편향, 합성 데이터 한계, 유용한 프롬프트(역할/목적/맥락/제약/표 출력), 오답 대조와 반례.

## 7. 각 정답 해설 반드시 포함할 틀
- **정답:** [번호], 한 문장 결론.
- **지문 분석:** 목표, 확정된 사실, 제약과 위험, 주어진 자료와 확인 안 된 자료.

- **실무 검증 체크:** 독립 원본 확인, 사용한 버전/기간/단위, 반례/추가 자료/재현 방법.
- **시험 함정:** 정확히 어떤 단어(예: '모두', '무기한', '조건 충족') 때문에 판단이 달라지는지.
- **출처/불확실성:** 출처 링크는 해당 개념을 실제로 지지해야 함. 제공되지 않은 정답·표는 임의 작성하지 않음.
