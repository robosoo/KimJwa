## 버전·자료 관리
- `snapshots/`: 운영 사이트 백업 원본; 실수로 기존 문제를 누락하지 않도록 보존
- `scripts/`: 재현 가능한 문항 검증, 수정, 빌드 스크립트
- `reports/`: 검증 결과와 미해결 이슈
- `api/`: AI ChatGPT/Claude 서버 프록시(키 비저장 원칙)
- `tests/`: 수식·정답·정합성 회귀 테스트

## 재현 기준
원본 백업에서 빌드 시 90문항과 12과제 수를 보존합니다.
- 정답 위치 균형화
- 선택지 유사/완전 중복 검출
- 근거 문서, 정답 인덱스 및 해설 완결성 검사
- 임의의 시험 규칙을 공식 규칙으로 주장하지 않음

## 보안
개인 API 키는 GitHub에 기록하지 않습니다. 실습 답안·질문 로그도 기본적으로 각자 브라우저에 저장하며 공개 저장소에 업로드하지 않습니다.

### 협업 주의
- 운영 사이트는 현재 **Vercel에 파일 직접 배포**한 상태. **GitHub에 커밋한다고 자동 재배포되는 구성은 아님.**
- 원본 데이터는 `snapshots/parts/part-01.b64` ~ `part-05.b64`에 Brotli+base64로 보관됨. `scripts/build.mjs`가 이를 자동 복원해서 사이트 생성.
- 이후 편집자는 문제를 통째로 삭제하지 말고, 별도 데이터 파일로 문제·해설을 분리하는 리팩터링을 우선 수행할 것.
- API 키는 코드/커밋에 넣지 말 것. 공개 서비스에 서버측 유료 API 키를 설정하기 전 인증·요청 횟수 제한 구현이 필요함.

## 2026-10-11 무료 ChatGPT 개인 계정 모드 (배포 완료)
- **현재 기본 옵션:** 사이트의 AI 실전 과제 → '무료 ChatGPT로 AI 실습' → 'ChatGPT 로그인 · 열기' → 문제 질문/내 답안 평가 → ChatGPT 새 탭에 붙여넣기.
- 개인 ChatGPT Free / 유료 계정으로 chatgpt.com에 로그인하며, AI 호출이 본 사이트 안에서 자동으로 실행되는 것은 아님. 이 방식에는 개발자용 API 키·API 결제가 필요하지 않음.
- iPad Safari: 질문과 평가 프롬프트 복사 후 새 ChatGPT 탭에서 붙여넣기. 복사 권한이 막히면 화면의 프롬프트 텍스트 영역에서 수동 복사.
- ChatGPT에서 받은 피드백을 사이트의 '피드백' 칸에 붙여넣고 '피드백 저장'을 눌러 브라우저에 기록.
- API 기능은 접힌 '고급' 설정으로 분리. 별도 유료 API/개인 API 키가 없으면 자동 호출하지 않음. 공용 유료 AI Gateway 자동 인증을 비활성화하여 익명 방문자의 API 비용을 차단함.
- 실배포 사이트에서 무료 UI·로그인 버튼·피드백 저장 버튼·/api/status 경로 확인, 객관식 90/실무 12 및 빌드검사 유지.
- **제한:** 사이트는 외부 ChatGPT 대화 내용을 자동으로 읽거나 공식 점수로 저장할 수 없으며 AI 답변을 복사해 돌아와야 함. 외부 서비스의 사용자 인증과 ChatGPT의 대화 세션을 사이트 API 권한으로 재사용하는 구현은 아님.
