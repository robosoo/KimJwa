- 운영 사이트: https://skhynix-ai-hackathon-quiz.vercel.app/

- 데이터와 문제는 공식 기출이 아닌 자체 제작 연습용입니다.

## 버전·자료 관리
- `snapshots/`: 운영 사이트 백업 원본; 실수로 기존 문제를 누락하지 않도록 보존
- `scripts/`: 재현 가능한 문항 검증, 수정, 빌드 스크립트
- `reports/`: 검증 결과와 미해결 이슈
- `api/`: AI ChatGPT/Claude 서버 프록시(키 비저장 원칙)
- `tests/`: 수식·정답·정합성 회귀 테스트

## 재현 기준
원본 백업에서 빌드 시 90문항과 12과제 수를 보존합니다.
- 정답 위치 균형화
- 선택지 유사/완전 중복 검출
- 근거 문서, 정답 인덱스 및 해설 완결성 검사
- 임의의 시험 규칙을 공식 규칙으로 주장하지 않음

## 보안
개인 API 키는 GitHub에 기록하지 않습니다. 실습 답안·질문 로그도 기본적으로 각자 브라우저에 저장하며 공개 저장소에 업로드하지 않습니다.

### 협업 주의
- 운영 사이트는 현재 **Vercel에 파일 직접 배포**한 상태. **GitHub에 커밋한다고 자동 재배포되는 구성은 아님.**
- 원본 데이터는 `snapshots/parts/part-01.b64` ~ `part-05.b64`에 Brotli+base64로 보관됨. `scripts/build.mjs`가 이를 자동 복원해서 사이트 생성.
- 이후 편집자는 문제를 통째로 삭제하지 말고, 별도 데이터 파일로 문제·해설을 분리하는 리팩터링을 우선 수행할 것.
- API 키는 코드/커밋에 넣지 말 것. 공개 서비스에 서버측 유료 API 키를 설정하기 전 인증·요청 횟수 제한 구현이 필요함.

### 품질검사 범위와 남은 과제
완전 중복·구조 오류·정답 위치 균형·2개 약한 해설·문자열 오류는 처리. 나머지 90문항의 **근거 적합성, 정답의 논리적 타당성, 오답의 설득력**은 아직 모두 사람이 검토하지 않았음. 자동 검사 결과가 전체 검증 완료를 의미하지 않음.
