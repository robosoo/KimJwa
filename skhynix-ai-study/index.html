공개 체험의 업무 시나리오 형식을 참고했습니다. 외부 모의시험의 시간·질문 횟수·문항 수는 이번 대회의 공식 규칙을 의미하지 않습니다.

문항 목록

초록: 정답 · 빨강: 오답
파랑: 시험 선택 · 점선: 해설 봄

4P: 개념 이해 → 판단 연습 → 반도체 적용

Plan → Prompt → Probe → Protect

먼저 4P의 의미와 사고 순서를 익혀보세요. 정의·실행 방법·일상 사례를 읽은 뒤 8개의 판단 문제로 이해도를 확인합니다. 다음에는 반도체 사례에서 직접 4P를 적용하고 AI의 잘못된 답을 수정합니다.

참고: 프로그래머스 AX 교육의 4P 분류를 바탕으로 구성한 학습 과정입니다. 실제 SK하이닉스 시험의 공식 평가 기준은 아닙니다.

1. 4P 핵심 개념 · 반도체와 무관한 원리부터

Plan: 성공 기준을 정의한다 → Prompt: AI에게 검증 가능한 작업을 요청한다 → Probe: 독립 증거로 확인·반박한다 → Protect: 정보·권한·승인을 통제한다. 실제 업무에서는 네 단계를 반복하여 적용합니다.

2. 개념 이해 확인 · 4P 역할을 구별하기

8개 상황을 읽고 지금 가장 먼저 해야 할 행동의 단계를 선택하세요. 선택 후 바로 이유를 확인할 수 있습니다.

3. 반도체 상황에 개념 적용하기

6개 가상 사례를 Plan·Prompt·Probe·Protect 네 단계로 적용합니다. 각 사례에서 직접 작성·해설 비교(24단계) 후 가상 AI의 잘못된 답변을 찾고 프롬프트를 수정한 뒤 새로운 조건을 재판정해야 다음 사례로 넘어갑니다.

학습 내용은 동일 브라우저/프로필의 로컬 저장소에 보관됩니다. 실제 회사·고객·NDA·개인정보 원문을 입력하거나 승인되지 않은 외부 AI에 복사하지 마세요.

해설을 읽은 진도와 새로운 문제를 스스로 맞힌 기록은 따로 표시합니다.

프로그래머스가 이 역량을 중요하게 보는 이유

단순히 생성형 AI를 사용했는지가 아니라, 스스로 문제를 정의한 과정, 프롬프트의 맥락과 수정, 결과에 대한 반증·검산, 안전한 활용 책임을 분리해 관찰하려는 접근입니다. 공개된 베타 사례와 기업교육 자료를 참고했으며, 대회별 구체적 채점은 공개적으로 확인되지 않았습니다.

ChatGPT 활용 실습

자료 보호: 가상 예시만 사용하세요. 실제 회사·고객·개인정보·NDA 문서나 API 키를 개인 AI에 붙여넣지 마세요. 입력한 학습 기록은 이 브라우저의 localStorage와 내보낸 JSON에 남습니다.

자료와 요청문을 복사해 각자 ChatGPT 계정에서 질문하고, 여기로 돌아와 결과와 검증 과정을 기록하세요.

사이트에서 AI를 자동 호출하지 않습니다. ChatGPT에서 직접 실행하고, 질문 횟수는 선택한 연습 목표에 따라 스스로 기록합니다.
